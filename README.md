# Ola-Ride-Analysis-Dashboard-
This project presents an interactive Ola Ride Analysis Dashboard built using Power BI. It focuses on analyzing ride data to identify key insights such as booking trends, peak hours, revenue patterns, and cancellation rates. The dashboard helps in understanding customer behavior and improving operational efficiency.
The Ola Ride Analysis Dashboard is a data analytics project developed using Power BI to extract meaningful insights from ride-sharing data.

🔍 Key Features:

Analysis of total bookings, revenue, and ride trends
Identification of peak booking hours and high-demand locations
Ride cancellation analysis (customer & driver)
Interactive filters for dynamic data exploration

🛠 Technologies Used:

Power BI (Data Visualization & Dashboard)
Excel (Data Cleaning & Preprocessing)
DAX (Data Analysis Expressions for calculations)

Cleaned and transformed raw data
Created data models and relationships
Built interactive dashboards and KPIs
Generated insights for better decision-making
